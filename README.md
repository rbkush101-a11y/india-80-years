# 🇮🇳 IN INDIA 80

### India's Journey to the Future

An interactive cinematic web experience created to celebrate
India's Independence Day and explore the journey from
independence to a technology-driven future.

---

## ✨ Features

- 🇮🇳 Cinematic Independence Day experience
- 🎬 Animated loading screen
- ⚡ SYSTEM READY intro sequence
- 🎵 Background cinematic music
- 🔊 Sound ON/OFF control
- 🖱️ Custom cursor
- ☸️ Animated Ashoka Chakra
- 🎆 Tricolor fireworks
- 🗺️ Interactive India experience
- 💻 Technology showcase
- 🚀 India 2047 vision section
- 📱 Responsive design
- ✨ Smooth animations and transitions
- 👨‍💻 Developer portfolio section

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure |
| CSS3 | Design & Animations |
| JavaScript | Interactions |
| SVG | Graphics |
| CSS Animations | Cinematic Effects |

## 🎨 Design Concept

The website follows a dark cinematic interface combined
with India's tricolor identity.

### Color Palette

- 🟠 Saffron — Courage & Sacrifice
- ⚪ White — Peace & Truth
- 🟢 Green — Growth & Prosperity
- 🔵 Navy Blue — Ashoka Chakra
